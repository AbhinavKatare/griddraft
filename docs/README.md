# Documentation Directory (`/docs`)

This directory contains technical specifications, energy market domain guides, architecture decisions, and engineering standards for the power forecast platform.

## Index of Documents

* **[conventional-commits.md](./conventional-commits.md):** Specification guide for commit messaging, PR titles, and semantic versioning.
* **[domain-guide.md](./domain-guide.md):** Comprehensive reference on GB power market mechanics: Settlement Periods, Elexon BMRS datasets (`FUELHH`, `WINDFOR`), Day-Ahead auction timelines (EPEX SPOT & Nord Pool), and point-in-time calculation rules.
* **[architecture-decisions.md](./architecture-decisions.md):** Architecture Decision Records (ADRs) explaining technology choices, caching patterns, and trade-offs.
